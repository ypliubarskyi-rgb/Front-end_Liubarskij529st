Демонстрація CSS Grid Layout

CSS Grid — це потужна двовимірна система компонування, яка дозволяє одночасно керувати як рядками, так і стовпцями вебсторінки. На цій сторінці загальний каркас побудовано за допомогою властивості grid-template-areas.
